# Label printer LP-200 (example)

A made-up device, to show what a spec sheet looks like as a card.

## Specs

| Item | Value |
|---|---|
| Print method | Direct thermal |
| Resolution | 203 dpi |
| Label width | 25-104 mm |
| Print speed | Up to 150 mm/s |
| Connection | USB-C, Wi-Fi |
| Power | 24 V DC, 2.5 A |

## Common settings

- Darkness: 10 for paper labels, 14 for synthetic labels
- Calibrate after every label roll change: hold Feed for 3 seconds
- Default network name: `LP200-XXXX` (last four digits of the serial)

## Error lights

| Light | Meaning |
|---|---|
| Red, steady | Out of labels or cover open |
| Red, blinking | Label jam |
| Orange, blinking | Print head too hot, wait a minute |
