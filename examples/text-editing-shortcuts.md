# Text editing shortcuts

The ones that work in most apps.

## Copy and paste

| Keys | Action |
|---|---|
| `Ctrl + C` | Copy |
| `Ctrl + X` | Cut |
| `Ctrl + V` | Paste |
| `Ctrl + Z` | Undo |
| `Ctrl + Shift + Z` | Redo |

## Moving around

| Keys | Action |
|---|---|
| `Ctrl + Left` / `Ctrl + Right` | Jump a word |
| `Home` / `End` | Start / end of the line |
| `Ctrl + Home` / `Ctrl + End` | Start / end of the document |

## Selecting

| Keys | Action |
|---|---|
| `Shift + arrows` | Extend the selection |
| `Ctrl + Shift + Left` / `Right` | Select a word at a time |
| `Ctrl + A` | Select all |

## Finding

| Keys | Action |
|---|---|
| `Ctrl + F` | Find |
| `Ctrl + H` | Find and replace (in many editors) |
